# Calculator

A clean, modern calculator web app with a dark theme.

## Features

- **Basic arithmetic** — addition, subtraction, multiplication, division
- **Chained calculations** — evaluates step-by-step as you chain operators
- **Special functions** — AC (clear), +/− (toggle sign), % (percentage)
- **Keyboard support** — type numbers, operators, Enter, Escape, Backspace
- **Error handling** — division by zero shows "Error"
- **Responsive display** — text auto-shrinks for long numbers

## Tech Stack

- HTML5
- CSS3 (Grid layout)
- Vanilla JavaScript (ES6+)

## Getting Started

Simply open `index.html` in your browser — no build step required.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Input digits |
| `.` | Decimal point |
| `+ - * /` | Operators |
| `Enter` or `=` | Evaluate |
| `Escape` | Clear (AC) |
| `Backspace` | Delete last digit |
